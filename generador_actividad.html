Conectar con la planilla de Google

Seguir los pasos en orden. Primero descargar el Code.gs y luego configurar Apps Script.

  1. Descargar el archivo Code.gs:
  2. Abrir Google Drive y crear una planilla nueva (Google Sheets). ⚠ En caso de tener más de una cuenta de Google, abrir Google Drive en una ventana de incógnito (Ctrl+Shift+N) — de lo contrario Apps Script puede no abrirse correctamente.
  3. En la planilla, ir a Extensiones → Apps Script.
  4. Borrar todo el contenido del editor, pegar el contenido del archivo Code.gs y guardar (Ctrl+S).
  5. Ir a Implementar → Nueva implementación.
  6. Tipo: Aplicación web. Ejecutar como: yo. Quién tiene acceso: Cualquier usuario. Hacer clic en Implementar.
  7. Copiar la URL de la aplicación web y pegarla en el campo de abajo.
PASO CLAVE Pegar aquí la URL de la aplicación web

Sin esta URL la actividad no puede enviar las respuestas a la planilla.

⚠ Arranque en frío — primer envío del día La primera vez que alguien envía en el día, Apps Script puede tardar hasta 30 segundos en responder. El primer estudiante puede recibir la actividad pero no ver la corrección inmediata. Para evitarlo: abrir la URL de la aplicación web en el navegador 2 o 3 minutos antes de iniciar la actividad (esto "calienta" el servidor).

Descargar la actividad

El archivo HTML está listo para publicar.

✔ Todo listo El archivo HTML contiene todas las preguntas y se conecta a la planilla configurada. No funciona si se abre directamente desde la computadora — necesita estar en un servidor web.
  1. Comprimir el HTML en un .zip
    Hacer clic derecho sobre el archivo HTML descargado → Comprimir / Enviar a → Carpeta comprimida. El .zip debe contener solo ese archivo.
  2. Subir a CREA como Paquete de contenido web
    En el curso de CREA: Recursos → Agregar recurso → Paquete de contenido web. Seleccionar el .zip y guardar.
  3. Compartir el recurso con los alumnos
    Los alumnos acceden desde la plataforma. CREA sirve el archivo desde su servidor, por lo que el envío a la planilla funciona correctamente.
  1. Crear o usar un repositorio
    En github.com: New repository. Darle un nombre relacionado con la actividad (ej. ActividadConjuntos). Dejarlo público.
  2. Activar GitHub Pages
    En el repositorio: Settings → Pages → Branch: main → Save. GitHub Pages queda habilitado para ese repositorio.
  3. Subir el archivo HTML
    Add file → Upload files → subir el archivo descargado → Commit changes.
  4. Obtener y compartir la URL
    La URL tiene el formato https://USUARIO.github.io/REPO/actividad.html. Compartirla por Classroom, correo o cualquier otro medio. Los alumnos la abren desde cualquier dispositivo.
