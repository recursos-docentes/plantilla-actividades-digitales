🖥️ Generador de Actividades Interactivas

Actividades con corrección automática vía Google Sheets — Recursos Docentes

¿Cómo funciona?

El sistema tiene tres piezas que trabajan juntas:

⚙️

generador_escritos.html

Asistente de 4 pasos que produce el HTML de la actividad y el Code.gs

→
📄

actividad.html

Archivo generado: el estudiante lo abre en el navegador y responde

→
📊

Google Sheets + Apps Script

Recibe las respuestas, registra puntajes y salidas de pantalla

Flujo completo

  1. La docente usa generador_escritos.html para configurar la actividad y descargar el HTML final.
  2. Sube ese HTML a GitHub Pages o CREA para que tenga una URL pública.
  3. Configura el Code.gs en un Google Apps Script vinculado a una planilla nueva y despliega la Web App.
  4. Pega la URL de la Web App en el generador antes de descargar el HTML final (paso 3 del asistente).
  5. Los estudiantes abren la URL de la actividad, ingresan su nombre y responden en pantalla completa.
  6. Al enviar, las respuestas llegan a la planilla con corrección automática y el estudiante ve el resultado al instante.
Sin servidor propio. Todo corre en el navegador del estudiante. Google Apps Script actúa como backend gratuito. El HTML generado es completamente autocontenido.

El Generador — asistente de 4 pasos

Abrir generador_escritos.html en el navegador (doble clic o arrastrar). El asistente guía por 4 pasos y produce el HTML listo para publicar.

⚠ Antes de aplicar la actividad con los estudiantes Revisar todas las preguntas y sus respuestas correctas, especialmente si se usó IA para generar el JSON. Probar la actividad completa (desde el ingreso del nombre hasta el envío) para asegurarse de que todo quedó bien configurado y que las respuestas se registran correctamente en la planilla.
1

Configuración

  • Título de la actividad (visible para el estudiante).
  • Materia (aparece en el encabezado).
  • Instrucción inicial: texto que el estudiante lee antes de comenzar.
  • Tiempo límite en minutos (0 = sin límite). El cronómetro se inicia al entrar en pantalla completa.
  • Clave de sesión: identificador único en localStorage que impide reenvíos. Usar una clave distinta para cada actividad, por ejemplo conjuntos_2026_g1.
2

Preguntas

Agregar preguntas con los botones de tipo o importar un JSON. Ver la pestaña Tipos de pregunta para los formatos disponibles.

La barra de símbolos científicos (🔬) permite insertar superíndices, subíndices, letras griegas y operadores de química/física en cualquier enunciado o alternativa — hacer clic primero en el campo de texto y luego en el símbolo.

Cada pregunta tiene un campo de puntaje; el total se calcula automáticamente.

3

Planilla

Conectar la actividad con Google Sheets:

  1. Descargar el Code.gs (botón incluido en este paso).
  2. Abrir Google Drive y crear una planilla nueva. ⚠ Si se tienen varias cuentas de Google, abrir Drive en una ventana de incógnito (Ctrl+Shift+N); de lo contrario Apps Script puede no abrirse con la cuenta correcta.
  3. En la planilla: Extensiones → Apps Script.
  4. Borrar el contenido del editor, pegar el código del Code.gs y guardar (Ctrl+S).
  5. Implementar → Nueva implementación → Tipo: Aplicación web → Ejecutar como: yo → Acceso: Cualquier usuario → Implementar.
  6. Copiar la URL de la aplicación web y pegarla en el campo de este paso.
Arranque en frío: la primera ejecución del día puede tardar hasta 30 segundos. Abrir la URL de la Web App en el navegador 2–3 minutos antes de la clase para pre-calentar el servidor.
4

Descargar

Vista previa de la actividad y botón para descargar el HTML final con todo incluido.

Hacer clic en ⬇ Descargar actividad HTML. El navegador guarda el archivo en la carpeta de descargas. Ese archivo es el que se publica para los estudiantes.

Opción A — GitHub Pages

  1. Ir a github.com e iniciar sesión.
  2. Abrir el repositorio o crear uno nuevo (público).
  3. Hacer clic en Add file → Upload files.
  4. Arrastrar el HTML descargado y hacer clic en Commit changes.
  5. En el repositorio: Settings → Pages → Source: Deploy from a branch → rama main → carpeta / (root) → Save.
  6. Esperar 1–2 minutos. La URL de la actividad será:
    https://[usuario].github.io/[repositorio]/[archivo].html
Para actualizar: subir el HTML nuevo con el mismo nombre de archivo. La URL no cambia.

Opción B — CREA

  1. Comprimir el HTML en un archivo .zip (clic derecho → Comprimir / Enviar a → Carpeta comprimida).
  2. En CREA, ir a la sección Recursos del curso.
  3. Agregar recurso → Paquete de contenido web.
  4. Subir el .zip y publicar.
  5. CREA genera una URL que los estudiantes pueden abrir directamente.
El HTML es autocontenido. No depende de archivos externos. Se puede abrir directamente en cualquier navegador moderno.

Tipos de pregunta

El generador soporta 7 tipos. Todos permiten asignar puntaje independiente.

TipoCódigo JSONDescripciónCorrección
Opción única single Múltiple opción, una sola correcta. La alternativa correcta se indica con la letra: "a", "b", etc. Sí
Múltiple respuesta multi Múltiple opción, varias correctas. correct es un array: ["a","c"]. Sí (todas o nada)
V / F tf Verdadero o Falso. correct: "true" o "false". Sí
V / F / Sin Evidencia tfse Tres opciones: Verdadero, Falso o Sin Evidencia. correct: "true", "false" o "se". Útil para trabajar con argumentación y fuentes. Sí
Abierta open Respuesta libre en texto. La respuesta llega a la planilla para revisión manual. No
Emparejar match Relacionar columna izquierda con derecha. pairs: array de {"left":"…","right":"…"}. Parcial (por par)
Banco de palabras fill Completar espacios eligiendo palabras de un banco. Las palabras faltantes se marcan con [corchetes] en el enunciado. Se pueden agregar distractores con extraWords. Parcial (por hueco)

🔬 Barra de símbolos científicos

El generador incluye una barra de símbolos para preguntas de física, química y matemáticas. Hacer clic en un enunciado o alternativa para activarlo, luego clic en el símbolo deseado:

x²→ x⁰ x¹ x² x³ x⁴ x⁵ x₂→ x₀ x₁ x₂ x₃ x₄ α β γ δ ε θ λ μ π σ ω Δ Σ Ω → ⇌ ↑ ↓ ° ± × ÷ ≈ ≠ ≤ ≥ √ ∞

Importar desde JSON

En el paso 2, el botón Importar JSON permite cargar un array de preguntas de una vez. Formato:

[ {"type":"single", "text":"¿Cuál es el símbolo del Oxígeno?", "opts":["O","Ox","Og","O₂"], "correct":"a", "puntaje":1}, {"type":"tf", "text":"El agua hierve a 100°C a nivel del mar.", "correct":"true", "puntaje":1}, {"type":"tfse", "text":"Todos los metales son buenos conductores eléctricos.", "correct":"se", "puntaje":1}, {"type":"multi", "text":"¿Cuáles son gases nobles?", "opts":["Helio","Nitrógeno","Argón","Oxígeno"], "correct":["a","c"], "puntaje":2}, {"type":"match", "text":"Relacionar elemento con símbolo", "pairs":[{"left":"Sodio","right":"Na"},{"left":"Cloro","right":"Cl"}], "puntaje":2}, {"type":"fill", "text":"El [hidrógeno] tiene número atómico [1].", "extraWords":"oxígeno,carbono", "puntaje":2}, {"type":"open", "text":"Explicar el proceso de ósmosis.", "puntaje":3} ]

Generar preguntas con IA

Copiar el siguiente prompt en cualquier asistente de IA (Claude, ChatGPT, Gemini) para generar un JSON importable directamente en el generador:

Generá un array JSON de preguntas para una actividad educativa. Cada pregunta debe ser un objeto con estos campos: - type: "single" | "multi" | "tf" | "tfse" | "open" | "match" | "fill" - text: enunciado de la pregunta - opts: array de opciones (solo para single y multi) - correct: letra "a"/"b"... (single), array ["a","c"] (multi), "true"/"false" (tf), "true"/"false"/"se" (tfse), null (open, match, fill) - pairs: [{left, right}] (solo para match) - extraWords: palabras extra separadas por coma (solo para fill) - puntaje: número (1–5) Tema: [INDICAR EL TEMA] Cantidad: [N] preguntas Tipos a incluir: [INDICAR TIPOS] Responder SOLO con el JSON, sin explicaciones.

Planilla de respuestas y Code.gs

El Code.gs se descarga desde el Paso 3 del generador. Cada actividad genera su propio Code.gs con las respuestas correctas ya incluidas.

⚠ Múltiples cuentas de Google: si el equipo tiene más de una cuenta de Google configurada, abrir Google Drive en una ventana de incógnito (Ctrl+Shift+N) antes de crear la planilla. De lo contrario, Apps Script puede abrirse con la cuenta incorrecta y fallar al implementar.

Pasos para configurar la planilla

  1. En el Paso 3 del generador, descargar el Code.gs.
  2. Abrir Google Drive y crear una planilla nueva (Ctrl+Shift+N si hay varias cuentas).
  3. En la planilla: Extensiones → Apps Script.
  4. En el editor de Apps Script, borrar todo el contenido existente.
  5. Pegar el contenido del Code.gs descargado y guardar (Ctrl+S).
  6. Hacer clic en Implementar → Nueva implementación.
  7. Configurar: Tipo → Aplicación web / Ejecutar como → Yo / Acceso → Cualquier usuario.
  8. Hacer clic en Implementar y copiar la URL generada.
  9. Volver al generador y pegar esa URL en el campo del Paso 3.
Primera ejecución del día (arranque en frío): Google Apps Script puede tardar hasta 30 segundos en responder la primera vez. Abrir la URL de la Web App directamente en el navegador 2–3 minutos antes de iniciar la clase para evitar demoras.

Publicar la Web App

Este paso se realiza una sola vez por actividad (o cuando se cambian las preguntas/puntajes).

1

Abrir el editor de Apps Script

En la planilla de Google Sheets: Extensiones → Apps Script.

2

Pegar el Code.gs

Borrar todo el contenido existente y pegar el código descargado desde el generador. Guardar con Ctrl+S.

3

Nueva implementación

Implementar → Nueva implementación

  • Tipo: Aplicación web
  • Ejecutar como: Yo (mi cuenta)
  • Quién tiene acceso: Cualquier usuario

Hacer clic en Implementar y autorizar los permisos si se solicitan.

4

Copiar la URL

Copiar la URL de la aplicación web (comienza con https://script.google.com/macros/s/…/exec) y pegarla en el campo del Paso 3 del generador.

Actualizaciones: si se modifica el Code.gs (por cambiar preguntas o puntajes), usar Implementar → Administrar implementaciones → editar la implementación existente — no crear una nueva, para mantener la misma URL.

Pegar la URL de la Web App

La URL del Apps Script se ingresa en el Paso 3 — Planilla del generador, antes de descargar el HTML final.

¿Dónde pegarla?

En el campo que aparece después de los pasos de configuración del Paso 3, con la etiqueta "URL de la Web App". Una vez pegada, el generador la incorpora directamente en el HTML de la actividad.

Importante: si se olvida pegar la URL antes de descargar, el HTML generado no podrá enviar respuestas a la planilla. Si eso ocurre, volver al generador, pegar la URL e importar las preguntas (o usar la función de importar JSON) para no tener que reescribir todo.

Verificar que funciona

Abrir la URL de la Web App directamente en el navegador. Debe responder con algo como:

{"status":"ok"}

Si responde así, la Web App está activa y lista para recibir envíos.

¿Qué pasa si la URL cambia?

Si se crea una implementación nueva (en vez de actualizar la existente), la URL cambia. En ese caso hay que volver a pegar la URL nueva en el generador y descargar el HTML de la actividad nuevamente.

Lo que ve el estudiante

La actividad generada es un archivo HTML autocontenido que el estudiante abre desde una URL.

Flujo del estudiante

  1. Abrir la URL de la actividad en el navegador.
  2. Ingresar su nombre y hacer clic en Comenzar.
  3. La actividad solicita entrar en pantalla completa.
  4. El cronómetro (si está configurado) comienza al entrar en pantalla completa.
  5. Responder todas las preguntas y hacer clic en Enviar.
  6. Ver la corrección inmediata con puntaje y retroalimentación por pregunta.

Pantalla completa y detección de salidas

⚠ Los navegadores no permiten bloquear la tecla Escape por razones de seguridad — es un comportamiento del sistema operativo/navegador que no puede desactivarse por código.

En cambio, la actividad detecta cuando el estudiante sale de pantalla completa (por Escape u otro medio) y:

  • Muestra una pantalla de bloqueo que cubre toda la ventana con un mensaje de aviso.
  • Pausa el cronómetro mientras el estudiante está fuera de pantalla completa.
  • Registra la cantidad de salidas y las envía con las respuestas a la planilla (columna Salidas pantalla).
  • El estudiante solo puede continuar haciendo clic en "Volver a pantalla completa".

Esto permite a la docente identificar en la planilla qué estudiantes salieron de pantalla completa y cuántas veces lo hicieron.

El envío no es automático. La actividad no se envía sola cuando el estudiante sale de pantalla completa. El estudiante debe hacer clic en Enviar para enviar sus respuestas.

Anti-doble-envío

La clave de sesión configurada en el Paso 1 se guarda en localStorage del navegador al enviar. Si el estudiante intenta abrir la actividad de nuevo en el mismo navegador y computadora, verá un mensaje indicando que ya la envió.

Nota para iOS (iPad/iPhone): Safari en iOS tiene soporte limitado para la API de pantalla completa. La actividad funciona pero no puede forzar pantalla completa en esos dispositivos. Recomendado usar Chrome o Firefox en computadoras de escritorio.

Retroalimentación instantánea

Al enviar, el estudiante ve:

  • Puntaje total obtenido sobre el máximo posible.
  • Cada pregunta con indicación de ✓ correcta o ✗ incorrecta.
  • Para las incorrectas, la respuesta correcta.
  • Las preguntas abiertas se muestran sin corrección (quedan para revisión manual).

Publicar en GitHub Pages

GitHub Pages es la opción más sencilla para dar una URL permanente a la actividad sin costo.

1

Crear o usar un repositorio existente

Ir a github.com, iniciar sesión y crear un repositorio público (o usar uno existente).

2

Subir el HTML

En el repositorio, hacer clic en Add file → Upload files. Arrastrar el HTML generado y hacer clic en Commit changes.

Nombrar el archivo de forma descriptiva, por ejemplo conjuntos_clase3.html.

3

Activar GitHub Pages

En el repositorio: Settings → Pages. En Source seleccionar Deploy from a branch, rama main, carpeta / (root). Guardar.

GitHub genera la URL en unos segundos (puede tardar hasta 1 minuto la primera vez).

4

Compartir la URL

La URL tiene la forma https://[usuario].github.io/[repositorio]/[archivo].html. Compartirla con los estudiantes por CREA, WhatsApp o proyectarla en clase.

Actualizar la actividad: subir el HTML nuevo con el mismo nombre de archivo y hacer clic en Commit changes. GitHub Pages se actualiza en 1–2 minutos. Si la URL no cambia, tampoco hay que volver a compartirla.

Glosario

Apps Script / Web App
Servicio de Google que permite ejecutar código JavaScript en la nube. En este sistema actúa como backend: recibe las respuestas del estudiante vía URL y las escribe en Google Sheets. La implementación como "Aplicación web" le da una URL pública accesible desde cualquier navegador.
Arranque en frío
La primera ejecución diaria de un Apps Script puede tardar hasta 30 segundos porque Google "duerme" los servidores inactivos. Para evitarlo, abrir la URL de la Web App en el navegador unos minutos antes de la clase.
Code.gs
Archivo de código Google Apps Script generado automáticamente para cada actividad. Contiene las respuestas correctas, los puntajes, y la lógica para recibir y registrar envíos en la planilla. Se descarga desde el Paso 3 del generador.
Clave de sesión (localStorage)
Identificador único que se guarda en el navegador del estudiante al enviar la actividad. Evita que el mismo estudiante envíe dos veces desde la misma computadora. Usar una clave diferente para cada actividad (ej: funciones_2026_g2).
JSONP
Técnica para enviar datos entre dominios distintos sin necesidad de un servidor intermediario. El HTML de la actividad usa JSONP para comunicarse con el Apps Script de Google, evitando las restricciones de CORS del navegador.
Pantalla completa forzada
Al comenzar la actividad, el navegador entra en pantalla completa ocultando la barra de tareas y otras pestañas. Si el estudiante sale de pantalla completa (por Escape u otro método), la actividad muestra una pantalla de bloqueo que pausa el cronómetro y registra la salida. El estudiante debe volver a pantalla completa para continuar. Cada salida queda registrada en la columna Salidas pantalla de la planilla. Nota: los navegadores no permiten bloquear la tecla Escape por razones de seguridad del sistema.
Salidas pantalla
Columna en la planilla de Google Sheets que registra cuántas veces el estudiante salió de pantalla completa durante la actividad. Permite identificar posibles intentos de consultar otras pestañas o recursos.
Tipo tfse (V / F / Sin Evidencia)
Variante del tipo Verdadero/Falso que agrega una tercera opción: "Sin Evidencia", para afirmaciones que no pueden responderse con los datos disponibles. Útil en actividades de pensamiento crítico y argumentación. La respuesta correcta puede ser "true", "false" o "se".
Barra de símbolos científicos
Panel en el generador (Paso 2) que permite insertar superíndices, subíndices, letras griegas y operadores de física/química (→ ⇌ ° ± × ÷ ≈ √ ∞) directamente en los enunciados y alternativas de las preguntas.
GitHub Pages
Servicio gratuito de GitHub que publica archivos estáticos (HTML, CSS, JS) con una URL pública. Ideal para distribuir las actividades sin necesidad de hosting propio.
